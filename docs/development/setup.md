# Configuración de desarrollo

Instala Node.js 22 LTS, npm, Git y Docker Desktop. Ejecuta `npm install`, copia `.env.example` a `.env.local` y usa credenciales de Supabase local. Inicia la aplicación con `npm run dev`; inicia la infraestructura con `npm run supabase:start`. Consulta `README.md` para los comandos completos.
