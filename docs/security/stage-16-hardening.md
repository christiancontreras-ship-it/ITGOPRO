# Etapa 16: hardening

Esta etapa implementa controles verificables y evidencia de preparación; no representa una certificación ISO 27001 ni SOC 2. Incluye CSP/HSTS, RLS, escaneo de secretos, rate limiting básico, riesgos e incidentes, solicitudes de privacidad y planes de continuidad.

El limitador en memoria protege una instancia; producción debe usar un almacén distribuido. Las pruebas de restauración y las notificaciones legales requieren procedimientos operacionales externos antes del go-live.
