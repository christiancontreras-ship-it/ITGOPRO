# Decisiones iniciales

1. **Next.js App Router:** convenciones actuales, Server Components y Route Handlers.
2. **TypeScript estricto:** errores detectados antes de producción.
3. **Supabase y PostgreSQL:** Auth, Storage y Realtime integrados; esquema administrado con SQL, sin Prisma.
4. **RLS desde el inicio:** las tablas del esquema público se cierran por defecto; las políticas llegarán con casos funcionales reales.
5. **Arquitectura modular:** límites por responsabilidad sin anticipar dominios inexistentes.
6. **Repositorio único:** coordinación sencilla en la fase inicial.
7. **Implementación incremental:** una etapa aprobada a la vez, sin funcionalidades simuladas.
