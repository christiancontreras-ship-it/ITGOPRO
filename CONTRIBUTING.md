# Contribuir a ITGO

Trabaja sobre una rama corta, limita cada cambio a una etapa aprobada y utiliza commits semánticos. Antes de solicitar revisión ejecuta `npm run format:check` y `npm run validate`. Toda modificación de esquema debe incluir una migración Supabase reproducible, RLS explícita y pruebas acordes al riesgo. No confirmes secretos, datos reales ni archivos `.env`.
